# Account roles and workflow assignments

The owner-approved collaboration model retains four public sign-in choices and five existing stored account roles. A sign-in choice is a presentation choice; authentication and server-side authorization determine what an account can do.

| Public sign-in choice | Existing stored account role | Workspace and responsibility |
| --- | --- | --- |
| Editor-in-Chief | `eic` | Editorial oversight, reviewer coordination and manuscript decisions. |
| General / Copy Editor | `editor` | Authorized editorial work, including initial editing, final editing and formatting assignments. |
| General / Copy Editor | `formatter` | Existing compatibility account role for assigned formatting work. |
| Peer Reviewer | `reviewer` | Review assigned manuscripts and submit feedback. |
| Author / Submitter | `author` | Manage drafts, submit and revise manuscripts, and track their progress. |

There is no separate Formatter card. Existing `formatter` accounts remain supported and sign in using General / Copy Editor; they are not converted to `editor`. Initial Editor and Final Editor are workflow assignments for Editor accounts, not additional stored account roles or sign-in choices. An Editor account does not automatically receive a formatting, initial-editing or final-editing assignment. The relevant server-side role, assignment, manuscript and workflow checks remain authoritative.

Registration creates Author accounts. Changes to account roles, authentication, assignment permissions or data migration require a separately approved design; this description makes no such change.
